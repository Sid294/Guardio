# Guardio 

Guardio is a live cyber defense simulation platform that lets you visualize and monitor cyberattacks as they hapen all over the world.

The platform simulates attacks such as DDoS, and more and APTs across a global network. Users can watch attacks spread, view affected systems, monitor security alerts, and see automated defenses happen in real time.

## How to Use

1. Open https://guardio-one.vercel.app/.

2. Click **START SIM** to begin

3. Explore the different views:
   - **Threat Map**
   - **Infrastructure Graph**
   - **Timeline**
   - **Intelligence**
   - **AI Copilot** 

4. Use the attack buttons to simulate different cyber threats:

5. Watch as the system detects threats and applies defensive actions.
